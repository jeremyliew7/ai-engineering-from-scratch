## 讲解、纠正与验证范围

- printf 的 `%s` 输出字符串，`\n` 换行；格式按剩余参数重复使用。学习者正确预测带 loss= 前缀的两行输出。
- `2>&1` 复制标准输出当时的去向；`> file 2>&1` 合并到文件，反序通常让标准错误继续输出到终端。首次误答反序警告进入文件，解释后选对 A；反序实验未核验。
- fg 等待剩余运行时间，不重新从 120 秒计时；Ctrl+C 终止，Ctrl+Z 暂停，bg 在后台恢复。
- tmux 和 nohup 不保证机器重启或 WSL 关闭后任务继续；单独 `&` 不提供可靠的断线保活保证。
- SSH/scp/rsync 为概念练习，未连接实际远程主机或传输文件。正确预测源目录尾斜杠得到 ~/data/train.csv；本地 8890 转发远程 8888 时浏览器访问本地 8890。
- alias 属于当前 Shell；写入 .bashrc 后，已有 Shell 仍需显式重新加载。未修改 .bashrc，未整体加载教材 shell_aliases.sh。
- 理解 tee 同时显示和写文件、tee -a 追加；tail -f、nohup 和 tee 实验未获得可核验终端输出。没有真实长时间训练断线实验。
- 未运行 nvtop、tmux 中 Python 训练演示或教材全部扩展命令；使用 watch/top/htop 完成分屏和监控练习。
- 教材批量按名称终止训练的别名可能误伤其他任务，未执行；本课无源码变更，不运行课程源码测试套件。
